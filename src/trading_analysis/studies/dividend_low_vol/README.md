# 红利低波：公开指标与校准复现

2026-11-08更新：新增真实分钟行情、校准参数、估值候选源、评分代理和逐项验证程序。
**当前运行与验证说明以 [RUNBOOK.md](RUNBOOK.md) 为准**；下文保留早期默认公共公式的说明。
使用 `calibrated_config()` 才是最新复现口径，默认 `IndicatorConfig()` 仍保留原有公开公式基线。

本模块根据「复利时光」2026-11-06 笔记的指标图，实现可明确计算的基础指标。
来源：[2026.11.6 红利低波，指标更新](https://www.xiaohongshu.com/explore/6aed5df300000000090021da)。

**这是透明的研究实现，不是原作者代码，也不包含原作者的完整综合评分和买卖策略。**

## 使用

```python
from trading_analysis.studies.dividend_low_vol import compute_indicators, grade_score, yield_spread

# prices: 按日期递增的 date, open, high, low, close, volume DataFrame
indicators = compute_indicators(prices)
spread = yield_spread(4.70, 1.60)  # 3.10 个百分点
observed_grade = grade_score(31.7)  # D，仅对给定评分分类
```

模块不联网，不修改输入，不补齐行情，不回填指标预热期；日期重复、倒序、缺失以及非法 OHLCV 会报错。
输入标的、复权方式、数据时间及数据供应商由调用者记录。缺失窗口或分母为零的指标保留 NaN。

## 已公开定义与本地实现约定

| 输出列 | 公开证据与实现 |
| --- | --- |
| `ma250`, `ma250_bias_pct` | 图 4 指明 250 日均线；用包含当日的简单均线，偏离为 `(close / MA250 - 1) × 100` |
| `rsi14` | 图 3 指明 RSI(14)，提到 Wilder；本地用首 14 个涨跌的简单均值初始化，再用 1/14 平滑。初始化法未获原作者确认 |
| `momentum_5d_pct`, `momentum_10d_pct`, `momentum_20d_pct` | 图 4 的 5、10、20 日涨跌幅；本地为 `close / close.shift(n) - 1` 的百分数 |
| `kdj_k`, `kdj_d`, `kdj_j` | 图 3 指明日 K (9,3,3)；本地从首个完整 9 日高低价窗口起算，K/D 初值 50，递推系数 1/3，J=3K−2D。初值未确认 |
| `volatility_20d_ann_pct` | 图 7 指明 20 日收益标准差 × √252；本地为简单日收益、样本标准差 ddof=1，百分数单位。标准差自由度未确认 |
| `volume_ratio_20d` | 图 7 指明当日成交 / 20 日均量；本地均量含当日。原作者是否含当日、是否将午间成交量外推未确认 |
| `bollinger_20d_position_pct` | 图 2 指明 20 日 BB%B；本地使用上下各 2 标准差、ddof=1。倍数和自由度未确认，结果不裁剪为 0–100 |
| `price_52w_position_pct` | 图 7 指明 52 周位置；本地用过去 252 个交易日最高 high / 最低 low。原作者可能使用日历 52 周或收盘极值，尚未确认 |
| `close_change_streak` | 图 7 的连续上涨/下跌天数；本地按收盘相对前收计算，平价归零，正负代表方向 |
| `yield_spread()` | 图 5 明示 DY − 中国 10 年国债收益率；两个输入都用百分数值，差为百分点 |

`IndicatorConfig` 可调整 52 周窗口、布林倍数、标准差自由度、年化交易日数、KDJ 初值。
其他默认约定在函数与表中明确列出，不能将这些约定描述为已经还原的原作者参数。

## 评级与图表区间

`grade_score()` **只采用 2026-11-06 图 6 版本**：`<25 E`、`25–40 D`、`40–55 C`、`55–70 B`、`≥70 A`。
精确边界采用左闭右开，输入必须是 0–100 的有限数值。此前笔记文字出现过 57 分为 C、75.2 分为 B，
与本版本阈值不一致；可能存在版本变化或文字错误，不能用这一函数替代全部历史版本。

`indicator_band()` 返回图中区间描述，采用左闭右开。RSI 看板分段是 30、50、70、80；
这不同于方法介绍中「RSI <30 / >70」的独立择时条件，也不同于综合模型。不能混为同一策略。
所有区间名称只是对公开图表的分类复现，不自动生成买卖操作。

## 尚未还原的综合模型

图 6 描述了一套约 20 项特征的统计评分：按各指标历史区间对应的未来 60 个交易日收益取均值；
按 R²、方差贡献倒推预测权重（power score）；将加权结果在历史样本中转成 0–100 百分位。
特征完整清单、分桶界限、权重公式、训练窗口、相似分数容差和样本筛选方法尚未公开确认。
因此本模块**没有**创建自定义权重冒充原版评分，也没有复现声称的 60 日回测收益。

进一步验证需处理原文午间 11:30 行情、图中抓取时间与前一交易日估值之间的区别；
严格回测还必须在每个预测日仅使用当时已成熟的 60 日收益标签，避免未来数据泄漏。
